# Aventurine

I'm an interdisciplinary artist moving into machine-learning research and software. I build tools around local AI, agent-directed coding, and generative art, and I treat this work as a continuation of my art practice in a new medium.

## Current work

- [Edge0 iPhone port](https://github.com/Edge0-AI/Edge0/pull/3) - a Swift/MLX port that brings Edge0's storage and expert-execution path onto a physical iPhone 16. The current M0/M1 milestone passes CPU and Metal tests and evaluates routed and shared experts against the real checkpoint on-device.
- [Lightwell](https://github.com/AventurineDream/lightwell) - a deterministic stained-glass generator with per-tile motifs, chaotic material gradients, project save/open, and editable SVG export.
- [TeacherVibe](https://github.com/AventurineDream/teachervibe) - a local-first repository reader and code-annotation tool for people directing coding agents, including non-coders. It turns human review notes into a structured, ready-to-paste agent prompt.
- **Simulation Query** - an ongoing local research experiment about continuity, inference, and what an observed agent can infer about being observed.
